# c-basics · C 语言基本功

W2–W4 的练习代码。这一阶段的重点不是写出能跑的程序，是**把 C 语言讲到能被追问三层不出错**。

## 目录约定

一个练习一个 `.c` 文件，文件名说明它练什么：

```
c-basics/
├── 01-str-funcs.c        # 手写 strcpy/strncpy/memcpy/memmove/strlen/atoi
├── 02-endian.c           # 大小端的三种判断写法
├── 03-struct-align.c     # 结构体对齐、pragma pack、位域
├── 04-union-protocol.c   # 用 union 解析协议帧
├── 05-func-ptr.c         # 函数指针与回调注册
├── 06-ring-buffer.c      # 环形缓冲区
└── 07-state-machine.c    # 三种状态机写法对比
```

## 每个文件顶部写一段注释

```c
/* 目的：实现一个线程不安全但零拷贝的环形缓冲
 * 关键点：读写指针用位掩码取模（容量必须是 2 的幂）
 * 面试常问：满和空怎么区分 → 牺牲一个单元，head+1==tail 为满
 */
```

## W4 的交付物

`07-state-machine.c` 里要有一个能用的**表驱动 UART 命令解析器**（≤300 行，含环形缓冲）。
这是 W1 之后第一个能写进简历的东西。

---

**面试关联**：一面 80% 的问题出在这个目录里。指针、对齐、volatile、回调、状态机——这些不是"知识点"，是能不能干活的分水岭。
