# embedded-log

东北电力大学 · 电子信息工程 · 大二
目标：2027 年暑假拿到长三角（上海 / 苏州 / 杭州 / 南京）嵌入式方向实习

## 这里是什么

STM32 外设学习记录、C 语言基本功复盘、两个项目的源码。
每个实验目录下的 README 记录了**配置思路和踩过的坑**——代码证明会写，README 证明想过。
