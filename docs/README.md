# docs · 笔记与复盘

这个目录放三类东西，全部用 markdown，命名带周次前缀，方便按时间翻。

## 1. 周复盘 `w{N}-review.md`

每周日写，控制在 10 行以内，回答三个问题：

- 这周实际做了什么（对照周计划，完成的打勾、没完成的写原因）
- 卡在哪里、怎么解决的
- 下周要提前注意什么

## 2. 踩坑记录 `坑-{主题}.md`

每遇到一个值得记的问题就单独写一篇。格式固定：

```
现象：串口收到乱码
排查：先量波特率 → 再查 TX/RX 是否交叉 → 最后看时钟配置
原因：HSE 实际 8MHz，CubeMX 里写成了 12MHz，波特率算错
解决：改 RCC 配置
教训：以后先确认晶振实物频率再配时钟树
```

## 3. C 语言自测 `w1-c-selfcheck.md`

W1 的错题归档。每道错题写三行：我当时怎么想的 / 错在哪一步 / 正确理解是什么。
按四类归档：指针与内存、关键字与编译、位操作与结构体、语法细节。

---

**为什么值得写**：面试被问"讲一个你调试过的问题"，答案就藏在这里。三个月后你自己也记不住，当时的三十秒记录能救你两小时。
