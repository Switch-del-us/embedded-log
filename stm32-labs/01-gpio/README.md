# 01 · GPIO 按键长短按识别

> 这是本仓库实验 README 的**模板**。后面 02–05 都照这个结构写，别自创格式。

## 目标

用定时器周期扫描实现按键短按 / 长按识别，主循环不阻塞（不用 `HAL_Delay` 死等）。

## 硬件与 CubeMX 配置

| 项目 | 配置 | 为什么 |
|---|---|---|
| 时钟 | HSE 8MHz → PLL×9 → 72MHz | 板载晶振实测 8MHz，别照抄教程写 12MHz |
| PA0 | GPIO_Input，上拉 | 按键接地，未按下时靠内部上拉保证高电平 |
| TIM3 | 1ms 周期中断 | 扫描周期决定消抖窗口，1ms 够用且开销小 |
| NVIC | 抢占优先级 2，子优先级 0 | 与串口中断配合，数值越小越优先 |

## 实现思路

1. 1ms 中断里对 PA0 采样，连续 20 次同电平才认为是稳定状态（20ms 消抖）
2. 稳定为低电平 → 进入 `PRESSED`，记下时间戳
3. 稳定为高电平 → 判断按住时长：< 800ms 为短按，≥ 800ms 为长按
4. 结果写入一个事件队列，主循环取走处理，中断里不做任何耗时操作

## 踩的坑

1. **现象**：长按松手后被识别成两次短按
   **原因**：松手瞬间的抖动被当成了新的按下沿
   **解决**：加了一个 20ms 的 `RELEASE_CONFIRM` 中间态，确认稳定后才回到 `IDLE`

2. **现象**：偶尔漏按
   **原因**：把扫描放在 `HAL_Delay(10)` 的主循环里，串口打印阻塞时采样点丢失
   **解决**：改到定时器中断里采样，主循环只消费事件
