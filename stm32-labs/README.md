# stm32-labs · 外设实验

W5–W8，一个外设一个目录，序号即学习顺序。

## 实验清单

| 目录 | 外设 | 核心内容 | 周次 | 状态 |
|---|---|---|---|---|
| `01-gpio/` | GPIO / EXTI | 八种模式选型、按键消抖、中断优先级 | W5 | 待开始 |
| `02-tim/` | TIM | PWM、输入捕获测频、编码器接口 | W6 | 待开始 |
| `03-uart/` | UART / DMA | 环形缓冲、空闲中断 + DMA 收不定长 | W7 | 待开始 |
| `04-adc/` | ADC | 多通道扫描、DMA、两点校准、滤波 | W7 | 待开始 |
| `05-i2c/` | I2C / SPI | 时序、软件模拟、读写 W25Qxx | W8 | 待开始 |

## 每个实验目录里有什么

- `README.md` —— 必填。目标 / CubeMX 配置 / 实现思路 / 踩的坑（模板见 `01-gpio/README.md`）
- 关键源码 `main.c`、`xxx.c`
- 完整 Keil 工程可选，但**必须确认 `Objects/`、`Listings/` 没被提交**（`.gitignore` 已处理）
- 现象截图或波形图放 `img/` 子目录

## 两个纪律

1. **一个实验做完再开下一个**，别同时开三个都半成品。半成品在面试里等于没做。
2. **每个实验至少留一个"当时想不通、后来想通了"的点**，写进 README 的踩坑段。没有的话说明你只是在抄例程。
