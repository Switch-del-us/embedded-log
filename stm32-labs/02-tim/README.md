# 02 · 定时器：PWM / 输入捕获 / 编码器

## 目标

一个实验里跑通三件事：PWM 输出呼吸灯、输入捕获测外部方波频率、编码器接口读正反转。

## CubeMX 配置

| 项目 | 配置 | 说明 |
|---|---|---|
| TIM1_CH1 | PWM Generation | 72MHz / (71+1) = 1MHz 计数，ARR=999 → 1kHz PWM |
| TIM2_CH1 | Input Capture | 上升沿捕获，两次捕获差值算周期 |
| TIM4 | Encoder Mode | TI1 和 TI2 都开，四倍频计数 |
